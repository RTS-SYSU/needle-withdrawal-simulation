# 眼科机器人退针仿真

双击 [index.html](index.html) 用支持 WebGL 的浏览器打开。页面直接读取用户选中的文件，并用目录内的 Three.js r160 渲染，可离线运行。

在页首切换「案例仿真」和「手动仿真」。两种模式共用退针算法、三维视图、播放控制和当前帧读数。切换时保留已经导入的案例及选择、手动输入值和 RCM 阈值，并停在目标模式的初态。

## 案例仿真

点击「导入文件」选择自己电脑上的 UTF-8 CSV。每行对应一个案例，编号在同一文件内应唯一。CSV 在浏览器中读取，本仓库不提供案例文件。

```csv
case_id,algorithm,branch,center_x_um,center_y_um,center_z_um,q_0_um,q_1_um,q_2_um,q_3_um,q_4_um,violation_u,violation_reason
```

- `center_x_um` 到 `center_z_um` 是机器人原生 XYZ 下的球心坐标，`q_0_um` 到 `q_4_um` 依次对应页面上的 Q1 到 Q5，单位均为 μm。
- `violation_u` 记录一处已证违规进度，可填写 0～1 的小数或分数。比如上面的 `0.5` 会在进度条的 50% 处显示红色标记，点击可暂停并跳到该帧。标记表示 CSV 记录的单个进度点，右侧读数仍按当前帧实时计算。
- 从 `violation_reason` 提取违规类型，多项用顿号分隔。系统按类型在当前文件中首次出现的顺序编号，带「（回放）」的同名原因计入同一种。全称在「违规类型」筛选中查看，案例行只列代号。选多个类型时，匹配其中任意一种即可。分支可单选，有 CSV 分支时按 CSV 筛选，否则按计算分支。
- 左侧「CSV 分支」来自文件的 `branch`。右侧「当前帧」分别显示退针算法和计算分支。计算分支由 `OrdinaryExit.run` 的规则从电机初态独立算出。分支不符或算法不受支持时，该例仍可查看初态，播放和拖动进度禁用。
- 只有表头的有效 CSV 表示当前轮次有 0 个案例。导入失败会保留上次成功读取的文件和选择。
- 旧格式的 `q1_um` 到 `q5_um` 对应页面上的 Q1 到 Q5，缺少分支列时左侧显示「—」，右侧仍显示计算分支。

## 手动仿真

在左侧直接填写 Q1～Q5 或拖动滑块，单位为 μm。默认电机位置为 `(12500, 12500, 12500, 12500, 6000)` μm。球心可填写机器人原生 XYZ 的绝对坐标，单位为 mm，也可展开「从允许球冠取点」用两个角度选点。球心在允许球冠外时，输入区显示提示，仍可执行仿真。

修改输入后，页面更新计算分支及轨迹预览，并停在新的初态。输入为空或越出数值范围时，暂停播放并提示对应字段。

## 回放

导入后自动选中第一例并停在初态。点击「播放退针」，或拖动进度条查看一帧。拖动会暂停，切换案例和「回到初态」都会停在 0%。A、B 分支的刻度表示算法分段切换点。播放完整进度约 20 秒，百分比对应归一化路径进度。

三维视图默认使用「真实对照」相机，参考针杆位于画面右上，针尖朝左下伸向眼球。也可切换为「立体」或沿 X、Y、Z 方向观察。视角切换只改变相机，机器人坐标和仿真读数保持原值。「显示」菜单可独立开关默认 XYZ 坐标轴和以 RCM 为原点的坐标轴，两组坐标轴方向一致。默认显示原有的 XYZ 坐标轴。菜单中还可以调节轨迹、针杆轴线、球心允许范围和眼球透明度。

右侧读数跟随当前帧。每台电机的限位以 `[下限, 上限]` 显示。球心和针尖同时显示绝对 XYZ 与相对 RCM 的 XYZ，单位均为 mm。相对坐标用绝对坐标逐轴减去 RCM 的绝对坐标，保留机器人 XYZ 轴向。球心在单次播放中固定。位置下方显示正运动学算出的两个偏角 α、β，单位为度。

「RCM 偏离阈值」默认为 150 μm，可在右侧修改。针杆轴线到固定 RCM 的距离大于阈值时，读数整行高亮，三维视图中的针杆同步变色。针尖距内壁显示带符号的余量，负值对应球外。电机越限和针尖出球也会整行高亮。球面和负深度判定使用 1 μm 浮点容差，电机限位使用 0.000001 μm 浮点容差。仿真路径对应 OrdinaryExit.run，读数来自浏览器中的浮点计算。
